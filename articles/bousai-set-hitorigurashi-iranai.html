防災セットで一人暮らしにいらないもの・足りないもの
賃貸の在宅避難を前提に、減らす物と足す物を一覧で整理

公開日 2026-09-25 ・ 更新日 2026-09-25

結論（3行）

  • 一人暮らし・賃貸で「いらない（減らしてよい）」のは、ろうそく（余震中の火災の原因）、家族向けの重複品、持ち出し袋に入れた2Lの水（重すぎて背負えない）、手持ちのキャンプ用品と重なる物です
  • 反対に「足りない」ことが多いのは、在宅用の水と食料、トイレの回数、常備薬・メガネ・生理用品、現金、部屋全体を照らすランタンです
  • 買う前に「手持ち品の棚卸し→セットの中身と照合→重複を外す→不足を足す」の4ステップで考えると、無駄な買い物と置き場所の圧迫を同時に防げます

防災セットを選んでいると、「一人暮らしにこんなに要るのか」「これは使わないのでは」と迷う品目が出てきます。ワンルームや1Kは収納が少ないため、使わない物を抱えると、本当に必要な水やトイレの置き場所がなくなります。

この記事では、一人暮らしの賃貸住宅で建物が無事な場合の在宅避難を主な前提に、防災セットに含まれがちな品目を「減らしてよい物」「置き換えたい物」「足りない物」に分けて整理します。公的機関の備蓄の目安と公開情報をもとにした編集部の整理で、特定の商品を実際に使用した評価ではありません。住んでいる地域のハザードマップで浸水や土砂災害の危険がある場合は、避難所への移動を前提に、持ち出し袋をより重視してください。

前提: 一人暮らしの備えは「持ち出し袋」と「在宅備蓄」の2層

内閣府は、飲料水1人1日3リットルと食料を最低3日分、できれば1週間分備えることを目安としています（出典: 内閣府「災害に対するご家庭での備え」）。一方で、リュック型の防災セットは背負って歩ける重さに収める必要があるため、水や食料は1日分程度しか入っていないのが一般的です。

持ち出し袋（防災セット）在宅備蓄
役割避難所へ移動する間と、到着直後をしのぐ自宅で停電・断水の数日〜1週間を過ごす
重さ背負って歩ける重さ（目安は5〜10kg程度）制限なし（ただし置き場所の制約あり）
置き場所玄関の室内側、クローゼット入口ベッド下、クローゼット下段、キッチン、トイレ
水500ml1〜3本3日分9L〜1週間分21L
トイレ数回〜十数回分3日分15回〜1週間分35回

「いらないもの」を判断するときは、この2層のどちらに入れる物かを先に決めると迷いが減ります。持ち出し袋には重くて使う場面が少ない物は入れず、在宅備蓄には量が必要な物を回す、という分け方です。

一人暮らしで「いらない」または「減らしてよい」もの一覧

次の表は、防災セットや防災グッズのリストに入っていることが多いものの、一人暮らし・賃貸では優先度が低い、または別の物に置き換えたほうがよい品目です。「絶対に不要」という意味ではなく、収納と予算が限られる場合に後回しにしてよい物として読んでください。

品目判断理由代わりに
ろうそく外す余震で倒れると火災の原因になる。停電時は極力使わずLEDライトを使うよう消防当局が呼びかけているLEDランタン・ヘッドライト
持ち出し袋の中の2Lペットボトル在宅側へ移す1本2kgで、リュックが重くなり歩けなくなる持ち出し袋は500ml1〜2本、2Lは在宅備蓄へ
2人用・家族用の重複品外すペアセットを一人で持つと、同じ物が2つずつになる1人用セット＋在宅備蓄
大型のテント後回し集合住宅の在宅避難では使う場面が少なく、収納を大きく取るアルミブランケット・普段の毛布
寝袋（在宅用として）手持ちの寝具で代替可自宅にいる限り布団・毛布が使える冬は毛布1枚をクローゼットの取りやすい位置に
使い方の分からない多機能ナイフ・ロープ類減らす使い慣れていない道具は非常時に使えず、重さだけが増えるカッター1本・はさみ1本
口に合わない非常食の大量購入減らす期限前に食べきれず、入れ替えが止まる普段食べるレトルト・パックご飯のローリングストック
キャンプ用品と重なる物外すライト・浄水器・バーナーをすでに持っていれば重複する手持ち品を持ち出し袋の近くにまとめる

ろうそくについては、停電時の火災を受けて消防庁が「ろうそくは極力使わず、懐中電灯などを使う」よう呼びかけた経緯があります。地震の備えについては東京消防庁の「地震に対する10の備え」も参考になります。明かりは電池式のLEDに統一しておくと、予備電池の管理も一本化できます。

持ち出し袋に毛布や防寒着を入れる場合、丸めたままではかさばり過ぎて他の物が入らなくなることがあります。圧縮袋を使って小さくする方法は「非常持出袋がパンパンな人へ｜毛布・防寒着を圧縮袋で小さくして詰める方法」で整理しています。

「いらない」と思われがちだが、残したほうがよいもの

反対に、一人暮らしでは使わないように見えて、残しておいたほうがよい物もあります。

  • ホイッスル: 家具の下敷きになったとき、一人暮らしは気づいてくれる同居人がいません。声より少ない体力で助けを呼べます
  • 給水袋（ウォーターバッグ）: 断水時に給水所から水を運ぶ人が自分しかいないため、一人暮らしほど必要です
  • 筆記具・油性ペン: ドアへの安否の張り紙、配給・連絡先のメモに使います
  • 軍手より厚手の手袋: 割れた食器やガラスの片付けは、一人で全部やることになります
  • アルミブランケット: 軽くて場所を取らず、停電した冬の夜の保温に使えます

一人暮らしの防災セットで「足りない」もの一覧

防災セットは共通部分をまとめた商品なので、個人によって必要な物や、量が必要な物は不足しがちです。

足りない物セットに多い量一人暮らしの目安置き場所
飲料水500ml×数本3日分9L／1週間分21Lベッド下・クローゼット下段
主食1〜3食分3日分9食／1週間分21食キッチンの棚・引き出し
トイレ数回〜20回分3日分15回／1週間分35回トイレの棚・洗面所
部屋用の明かり手持ちライト1つ手元用1＋部屋を照らすランタン1寝室と玄関に1つずつ
常備薬含まれない3〜7日分持ち出し袋のポケット
メガネ・コンタクト用品含まれない予備1組持ち出し袋
生理用品含まれないか少量1周期分持ち出し袋と洗面所
現金含まれない1〜2万円程度＋小銭持ち出し袋の内ポケット

加熱手段含まれないカセットコンロ＋ボンベ数本キッチンの下の棚

トイレの回数は、経済産業省が1人1日5回・1週間で35回分を目安として案内しています（出典: 経済産業省）。断水時は水だけでなく、マンションの排水管が損傷していると水を流せないこともあるため、トイレは水と同じくらい優先度が高い備えです。

手回し充電ラジオは、発電量が小さく、スマホを実用的な残量まで充電するには長い時間回し続ける必要があります。スマホの電源は、満充電のモバイルバッテリーを別に用意するほうが確実です。停電が長引く地域や在宅勤務の人は、ポータブル電源も選択肢になります（「ポータブル電源は一人暮らしに何Wh必要か」参照）。

防災セットの形で変わる「いらないもの」

防災セットには大きく分けて3つの形があり、形によって一人暮らしで余りやすい物が変わります。

形特徴一人暮らしで余りやすい物向いている人
リュック型（1人用）持ち出し袋の中身がひととおり入る。重さは数kg程度手持ちのライト・救急用品と重なる小物防災用品をほとんど持っていない人
リュック型（2人用以上）同じ物が人数分入る2人目以降の分すべて同居人がいる人。一人暮らしには過剰
ボックス・バケツ型（在宅向け）水・食料・トイレを多めに入れた据え置き型持ち運び用の小物が少ない代わりに、容器が大きく場所を取る玄関や押入れに据え置きの場所がある人
ポーチ型（最小限）通勤バッグに入る程度の小物ほとんど余らないが、在宅用には量が足りない通勤・外出先での被災に備えたい人

一人暮らしで最も無駄が出にくいのは、1人用のリュック型＋在宅備蓄を自分で足す組み合わせです。ボックス型は在宅用として便利ですが、ワンルームでは置き場所を大きく取るため、ベッド下やクローゼットに分散して置ける単品の水・トイレのほうが収まりやすい場合があります。

住んでいる場所の災害リスクで変わる優先順位

「いらないもの」は、住んでいる地域でどの災害が起こりやすいかによっても変わります。自治体のハザードマップ（国土交通省の「ハザードマップポータルサイト」から確認できます）で、自宅の浸水・土砂災害の想定を確認してから優先順位を決めます。

想定される災害優先したい物後回しでよい物
地震（建物は無事で在宅避難）水・トイレ・明かり・家具の転倒防止雨具の追加、長靴
浸水・洪水（避難所へ移動）持ち出し袋、レインコート、防水袋、スマホの防水ケース在宅用の大量の水（上の階なら別）
台風・大雨の停電明かり、モバイルバッテリー、ラジオ、冷蔵庫の中身を減らす計画テント・寝袋
大雪・寒波の停電カイロ、毛布、カセットコンロ、湯たんぽ冷却用品

低層階で浸水の想定がある場合、ベッド下や床に置いた備蓄は水没する可能性があります。その場合は、持ち出し袋を高い位置（クローゼットの中段など、落下しない高さ）に置くことも検討します。

買う前の4ステップ: 棚卸し→照合→重複を外す→不足を足す

  1. 手持ち品の棚卸し: 懐中電灯、モバイルバッテリー、救急用品、レインコート、キャンプ用品、カセットコンロなど、すでに家にある物を書き出します。ここで見つかった物は買う必要がありません
  2. セットの中身と照合: 候補の防災セットの中身一覧を販売ページで確認し、棚卸しリストと重なる物に印を付けます
  3. 重複を外す判断: 重複が多い場合は、セットを買わずに不足分を単品で買うほうが安く、場所も取りません。重複が少なければ、セットでまとめて揃えるほうが早く終わります
  4. 不足を足す: 上の「足りない物」の表から、水→トイレ→明かり→個人用品の順に足していきます

この順番にするのは、水とトイレが「ないと生活できない物」で、量が必要なため置き場所を先に決める必要があるからです。明かりや個人用品は小さいので、あとからでもポケットに収まります。

ワンルームでの置き場所の割り当て

減らす物と足す物が決まったら、置き場所を割り当てます。ワンルーム・1Kの一般的な割り当て例は次のとおりです。

場所置く物ポイント
玄関の室内側持ち出し袋、靴、ヘルメット共用廊下には置かない。ふた付きボックスに入れると腰掛けにもなる

部屋を照らす明かり（ランタン）

手持ちの懐中電灯は一方向しか照らせず、停電した夜に食事やトイレをするには不便です。部屋全体を照らせる電池式のLEDランタンを1つ用意し、寝室に置きます。乾電池の規格（単3・単1など）を、持ち出し袋のライトとそろえると予備電池を共通化できます。

非常用トイレ（回数を増やす）

セットのトイレで3日分に届かない場合は、凝固剤と処理袋がセットになった非常用トイレを追加します。一人暮らしなら30〜50回分入りを1つ買うと、1週間分の35回をまかなえます。置き場所は「簡易トイレの収納場所」を参照してください。

持ち出し袋の中身をまとめて揃えるなら

手持ちの防災用品がほとんどなく、棚卸しで重複が少なかった場合は、セット品を1つ買って足りない物を足すほうが早く終わります。あかまる防災は、販売元が防災士・消防士監修の44点セットとして案内している製品です（広告主の表記に基づく紹介です。内容・価格は公式サイトでご確認ください）。中身と一人暮らしでの不足量は「あかまる防災の中身を一人暮らし目線で整理」で詳しくまとめています。

セットから外した物の置き場所

届いた防災セットから「一人暮らしには多い」と判断した物も、捨てる必要はありません。持ち出し袋から外して、別の場所で役割を持たせると、袋は軽くなり、備えの総量は減りません。

  • 重い水・食料: 在宅備蓄のキッチンやベッド下に移し、ローリングストックの一部として期限の近い順に使う
  • 予備の衛生用品（ウェットシート・マスク）: 洗面所やトイレの棚に移し、普段使いで回す
  • 重複したライト: 1つは寝室のベッド横、もう1つはトイレや玄関に置く。停電した夜に、どの部屋でも手の届く位置に明かりがある状態にする
  • 重複した救急用品: 職場のロッカーや通勤バッグに入れ、外出中の被災に備える

持ち出し袋を軽くして在宅側に回す考え方は、防災セットに限らず、備蓄全体を一人暮らしの狭い部屋に収めるときの基本になります。

予算が限られるときの優先順位

一度に全部を揃えなくてかまいません。予算が限られる場合は、次の順に揃えると、少ない出費で「生活できない状態」を先に防げます。

  1. 水3日分（2Lペット5本）: 普段の買い物で1ケース多く買うだけで済みます
  2. トイレ15回分: 断水・排水不可のときに代わりがありません
  3. 明かり（ヘッドライトかランタン1つ）: 夜間の停電で移動・トイレに必要です
  4. モバイルバッテリー: 情報収集と安否連絡の生命線です
  5. 常備薬・メガネ・現金: 家にある物を袋にまとめるだけで、費用はほぼかかりません
  6. 持ち出し袋（セット）: 在宅の備えがそろったあとで、避難が必要になった場合に備えます

全体のチェック項目は「一人暮らし防災収納チェックリスト」で確認できます。

よくある質問

一人暮らしに防災セットは必要ですか。自分で揃えるのとどちらがいいですか
手持ちの防災用品が少なく、何を買うか調べる時間がない場合はセットが早く済みます。キャンプ用品などで重複が多い場合は、不足分を単品で買うほうが安く、収納も圧迫しません。上の4ステップで棚卸ししてから判断してください。
ヘルメットは一人暮らしにも必要ですか
頭を守る物は、落下物のある場所を移動するときに役立ちます。収納が限られる場合は、折りたたみ式のヘルメットや、帽子と厚手のタオルで代用する方法もあります。持ち出し袋の近くに置いておくと、避難時に忘れません。
非常食は乾パンでなければいけませんか
いいえ。普段食べているパックご飯、レトルト食品、カップ麺、缶詰を少し多めに買って回すローリングストックで十分です。食べ慣れた物のほうが、期限切れで捨てることもなくなります。
ろうそくはアロマ用などで家にありますが、防災用に置いておいてもいいですか
普段使いは問題ありませんが、防災用の明かりとしては使わない前提にしてください。地震のあとは余震で倒れる危険があり、停電中の火災の原因になります。LEDライトを別に用意しましょう。
防災セットの中身は何年ごとに見直せばいいですか
半年に1回、中身の期限・電池・季節用品を確認するのが目安です。水・食料の期限が近づいたら普段の食事で食べ、同じ物を買い足します。
寝袋は本当にいらないのですか
建物が無事で自宅にいられる在宅避難なら、普段の布団や毛布が使えるため優先度は下がります。一方、浸水想定区域に住んでいて避難所への移動が前提の人や、寒冷地に住む人は、コンパクトな寝袋を持ち出し袋の近くに置く価値があります。住まいの条件で判断してください。

まとめ

一人暮らし・賃貸の防災セットで減らしてよいのは、ろうそく、家族向けの重複品、持ち出し袋の重い水、手持ち品と重なる物です。足りないのは、在宅用の水・食料・トイレ、部屋用の明かり、常備薬などの個人用品、現金です。手持ち品を棚卸ししてからセットの中身と照合し、水とトイレから順に置き場所を決めて足していけば、収納の少ない部屋でも無駄なく備えられます。
